# Translations
This repo contains all translation files for the Stellarity, Stellarity ~ Enlightened, and Recondite projects, open for anyone to contribute to! Look below to learn how to contrbute:

## Updating Translations
To update a translation, you must [Fork](https://github.com/Prismatic-Shards/translations/fork) the repo and create a [Pull Request](https://github.com/Prismatic-Shards/translations/pulls) with your changes. Originally, translations were done through weblate.ammir.dev, but the site is no longer functioning.

Before submiting your changes, make sure your fork is **up to date**. Submiting outdated commits can result in merge conflicts, which can result in your request taking a while to be merged or just being denied completely.

Once you submit your changes for review, please give the project manager up to a week to review. If a manager doesn't respond a week after submitting a request, feel free to send a message in your request. DO NOT PING US ON DISCORD!

## Adding New Translations
Not every language has a generated language file, especially newer projects such as Recondite. To create a new language file, you can ask a project manager in the project's Discord:
 
**Stellarity and Recondite**: [Prismatic Shards](http://discord.prismaticshards.xyz) 

**Stellarity ~ Enlightened**: [amber's cove](http://discord.coder2195.xyz)

## Translating Multiple Projects
If you are updating translations for multiple projects at the same time (such as Stellarity and Enlightened), please create seperate pull requests for each project's changes. Each project is managed by a different person, and involving muliple projects in one request would require multiple developers to agree. Not only will this make merging your changes take longer, it's also just annoying to deal with.
